# Security Policy

## Reporting

Do not disclose potential vulnerabilities through public issues.

For repositories maintained privately, report the finding directly to the repository owner through the private communication channel already established for the project.

## Sensitive information

Never include credentials, tokens, private keys, personal financial data, production data, or environment files in an issue, pull request, commit, log, or screenshot.

If sensitive information is committed accidentally:

1. Stop further distribution.
2. Notify the repository owner immediately.
3. Revoke or rotate the exposed credential.
4. Remove the secret from history using an approved remediation procedure.
5. Record the incident and corrective action privately.
